# COSC2349 — Assignment 2: 2D Top-View Shoot 'Em Up Game

## Overview
Design and implement a 2D top-view shoot 'em up game inspired by the Amiga/Atari ST classic **Xenon 2: The Megablast**.

- **Course:** COSC2349 (Games Studio 2)
- **Weighting:** 32% of final course mark
- **Type:** Group assessment, with individual responsibility
- **Due:** Sunday 13 September, 11:59pm AEDT (mid-semester break)
- **Submission:** Classroom50
- **Feedback:** Via Canvas
- **Late penalty:** 10% of total score deducted per calendar day late, unless an extension or special consideration is approved in advance

## Required Features
- Parallax scrolling background
- Enemy waves
- Power-ups
- Player-controlled spaceship
- Core game mechanics: physics, rendering, collision detection, and optimization for a 2D game environment

A graphics starter kit is provided by the course.

## Learning Outcomes Assessed
- **CLO1:** Broad technical knowledge of computer games software engine architecture
- **CLO2:** Applying that knowledge to design and implement computer games
- **CLO3:** Using and critically evaluating professional software tools/resources in modern game development
- **CLO4:** Working professionally in teams — self-directed and collaborative behaviour

## Rubric (32 pts total)

### Functionality — Core mechanics, parallax scrolling, enemies, power-ups (16 pts)
| Score | Description |
|---|---|
| 13–16 | All core mechanics implemented and working: parallax scrolling, enemy waves, power-ups, player-controlled spaceship. Fully playable, meets all requirements. |
| 10–13 | Most core mechanics implemented; minor issues; game playable, mostly meets requirements. |
| 7–10 | Some core mechanics missing or partially working; significant gameplay issues. |
| 0–7 | Major functionality missing; game unplayable or incomplete. |

### Technical Implementation — Code quality, structure, optimization (12 pts)
| Score | Description |
|---|---|

| 7–10 | Mostly clean code, some room for improvement; generally good performance. |
| 4–7 | Significant structural issues; performance below optimal. |
| 0–4 | Poorly structured or incomplete code; major performance issues. |

### Creativity and Polish — Visual/audio design, unique features (4 pts)
| Score | Description |
|---|---|
| 3–4 | High polish: visually appealing graphics, sound effects, music; creative/unique elements enhance gameplay. |
| 2–3 | Visually and audibly appealing; some creative elements present. |
| 1–2 | Basic visuals and audio; limited polish or creativity. |
| 0–1 | Lacks polish and creativity; visuals or audio poor or missing. |

## Notes for Agent Context
- Engine: Godot 4.5
- Target performance: 60 FPS, efficient rendering and collision detection
- Prioritize hitting all four required features (parallax scrolling, enemy waves, power-ups, player ship) before polish — Functionality is the highest-weighted criterion (16/32 pts)
- Code should be clean and well-structured per Technical Implementation criterion
